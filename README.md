# Тренажёр тестов

Открыть: https://abdurakhmon-sl.github.io/test-trainer/

- **Предметы.** Сначала выбирается предмет, тесты берутся только из него.
- **В каждом тесте ровно 25 вопросов.**
- **Подготовка.** Правильный ответ показывается сразу после каждого вопроса. Чаще попадаются вопросы, где студент ошибался, и его слабые темы.
- **Экзамен.** Ответы показываются только в конце. Вопросы выбираются случайно.
- **Работа над ошибками** после каждого теста, кнопка «Сначала мои ошибки».
- **Учить.** Вопрос и сразу правильный ответ, поиск, фильтр по темам, режим «скрыть ответы».
- Вопросы и варианты ответов каждый раз в новом порядке. Прогресс хранится в браузере.

## Как добавить тест

1. Создать файл `test-<название>.js` по образцу `test-medstat.js`. Поле `subject` задаёт предмет: тесты с одинаковым `subject` попадают в один предмет.
2. Добавить в `index.html` строку `<script src="test-<название>.js"></script>` рядом с остальными.

Формат вопроса: `id`, `q` (вопрос), `o` (варианты), `a` (номер правильного варианта, с 0), `t` (тема), `tf: 1` для «верно/неверно», `n` (подсказка, необязательно).

## Студенты (логин и пароль)

Список студентов лежит в файле `users.js`. Пароли там не хранятся, только их отпечаток.

1. Откройте https://abdurakhmon-sl.github.io/test-trainer/admin.html
2. Введите логин, имя и пароль студента, нажмите «Получить строку» и скопируйте её.
3. В репозитории откройте `users.js`, нажмите карандаш (Edit), вставьте строку перед `];` и нажмите Commit changes.

Чтобы закрыть студенту доступ, удалите его строку. Тестовый вход `test` / `test25` удалите, когда добавите своих студентов.

Статистика собирается по логину в Google Таблице «Тренажёр тестов: результаты студентов» (адрес сервера в `config.js`, код сервера в `server.gs`). Лист «Результаты»: каждый тест отдельной строкой. Лист «Студенты»: сводка по каждому логину. Прогресс студента подтягивается на любом устройстве после входа.

Результат отправляется в конце теста. Если интернета или сервера нет, он ждёт в очереди на телефоне и уходит позже. Незавершённый тест сохраняется: после перезагрузки страницы его можно продолжить.

Сервер принимает данные только от логинов из `users.js` и только с ключом, который получается из пароля. Новый студент начинает попадать в таблицу в течение 5 минут после добавления в `users.js`.
